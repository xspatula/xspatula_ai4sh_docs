## Project Purpose

`xspatula_ai4sh_docs` is a documentation site written in Markdown using the Jekyll theme Minimal Mistakes (https://mmistakes.github.io/minimal-mistakes/) for the database-integrated Xspatula framework written in python in the sibling repo `xspatula_ai4sh`. This site (`xspatula_ai4sh_docs`) is intended as instructions for how to seed and load soil data for the AI4SH (AI4SoilHealth) project using the Xspatula framework introduced in the sibling directory `xspatula_core_docs`.
